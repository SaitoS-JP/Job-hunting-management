# 実機テストのチェックリスト

自動テスト（`npm test`）とパソコン上のブラウザでの確認では分からない部分を、実際のスマホで確かめるためのリストです。上から順に試し、うまくいかなかった項目を報告してください。

## 報告のしかた

うまくいかなかった項目ごとに、次をまとめて送ってください。

- 項目の番号（例：2-3）
- 何が起きたか（期待どおりにならなかった点）
- 画面のスクリーンショット
- 機種と iOS / Android のバージョン（iPhone は「設定」→「一般」→「情報」）
- アプリのバージョン（メニュー →「使い方（よくある質問）」のいちばん下に表示）

## 準備

- できれば「まだ一度も開いていない」状態から始めます。すでに使ったことがある場合は、Safari のプライベートブラウズで開くか、別の端末を使うと初めての状態になります。
- URL：https://saitos-jp.github.io/Job-hunting-management/

## 1. 開く・ホーム画面に追加

| 番号 | 操作 | こうなれば正常 |
| --- | --- | --- |
| 1-1 | Safari で URL を開く | 「はじめかた」のカードが表示される。ほかのお知らせ（ホーム画面に追加の案内・バックアップのお知らせ）は出ていない |
| 1-2 | 共有ボタン →「ホーム画面に追加」→「追加」 | ホーム画面に「就活ボード」のアイコンができる（青い矢印のマーク） |
| 1-3 | ホーム画面のアイコンから起動 | アドレスバーのない全画面で開く。画面上部の時計・電池の表示と、タイトルや「メニュー」が重なっていない。画面下も切れていない |
| 1-4 | ホーム画面から開いたアプリで、もう一度「はじめかた」が出ているか確認 | Safari とホーム画面のアプリはデータが別なので、ここでも初めての状態になる（正常です） |

以降はホーム画面のアプリで試してください。

## 2. 企業を追加する

| 番号 | 操作 | こうなれば正常 |
| --- | --- | --- |
| 2-1 | 「＋ 企業を追加」を押す | 社名・職種・選考の種類・今の段階・次の予定（任意）だけが表示される |
| 2-2 | 社名をタップして入力 | 文字入力でキーボードが出ても、入力欄が隠れない。画面が拡大されない |
| 2-3 | 「次の予定」の日付をタップ | 日付を選ぶ画面が出る。選んだ日付が欄の中に収まって表示される（はみ出さない） |
| 2-4 | 時刻をタップして選ぶ | 時刻が「14:00」のように欄の中に収まって表示される |
| 2-5 | 予定の内容を入れて「保存」 | 一覧に企業が並び、「直近の予定」にその予定が出る。「はじめかた」の 1 と 2 に ✓ が付く |
| 2-6 | もう一度その企業を開き「詳しく入力する」を押す | 業界・志望度・URL・アイコン・メモなどが表示される |
| 2-7 | アイコンの「画像を選ぶ」で写真を選んで保存 | 一覧の頭文字アイコンが写真に変わる |

## 3. 予定と選考の進み具合

| 番号 | 操作 | こうなれば正常 |

## 6. カレンダーアプリへの書き出し（通知）

| 番号 | 操作 | こうなれば正常 |
| --- | --- | --- |
| 6-1 | iPhone の「カレンダー」アプリで「カレンダーを追加」→「就活ボード」という名前で作る | 専用カレンダーができる |
| 6-2 | 就活ボードのメニュー →「カレンダーに書き出し」→「すべて書き出す」 | ファイルの保存またはカレンダーへの追加の画面が出る |
| 6-3 | 追加先に「就活ボード」カレンダーを選んで追加 | カレンダーアプリに予定が入る。日時が正しい（時刻のない予定は終日） |
| 6-4 | カレンダーアプリで予定を開く | 通知が「3日前」「前日」になっている |
| 6-5 | 就活ボードで、書き出した予定の編集画面を開く（「予定」タブ） | その予定に「カレンダーに書き出し済み」と表示される。時刻を変えると、行の下に「保存後、カレンダー側の予定も変更してください」と出る |
| 6-5b | そのまま保存する | 画面の下に「書き出し済みの予定が変わりました：（前の日時）→（新しい日時）」と出る（「書き出しを開く」「閉じる」）。閉じたあとも、上に「カレンダーに取り込んだ予定と違いがあります（1件）。カレンダー側の予定も確認してください。」が残る |
| 6-5c | 書き出した予定がある企業で「辞退」を押す | 画面の下に「〇〇の「（予定）」の予定がなくなりました（辞退）」と出る。カレンダーアプリ側の予定は残っている（手で消す） |
| 6-6 | 6-2 と同じファイルをもう一度取り込む | 予定が重複する場合がある（iPhone の仕様）。その場合は専用カレンダーを削除して作り直し、「すべて書き出す」を取り込み直す手順で元に戻せるか |

## 7. バックアップ

| 番号 | 操作 | こうなれば正常 |
| --- | --- | --- |
| 7-1 | メニュー →「バックアップ」→「書き出し」 | ファイルの保存先を選ぶ画面が出て、「ファイル」アプリに保存できる。「はじめかた」の 4 に ✓ |
| 7-2 | 別の端末（またはプライベートブラウズ）で「読み込み」→ 7-1 のファイル →「置き換える」 | 同じ企業・予定・ES・条件・アイコンが表示される |
| 7-3 | 壊れたファイル（例：メモに適当な文字を書いて保存した .json）を読み込む | 何が問題かが表示され、データは変わらない |
| 7-4 | 「パスワードで保護する」にチェックし、8文字以上のパスワードを2回入れて「書き出し」 | ファイル名が `shukatsu-backup-日付-locked.json`。「ファイル」アプリで中身を開いても社名などが読めない |
| 7-5 | 7-4 のファイルを読み込み、わざと違うパスワードで「開く」 | 「パスワードが違うか、ファイルが壊れています」と出て、データは変わらない |
| 7-6 | 正しいパスワードで「開く」→「置き換える」 | 7-2 と同じように元に戻る。数秒以内に終わり、待っている間も画面が固まらない |
